## Как обновить рейтинги и число отзывов

Цифры живут в одном месте — **`reviews.json`** в корне:

```json
{
  "updated": "2026-08-23",
  "google": { "rating": 5.0, "count": 106 },
  "notino": { "rating": 4.9, "count": 117 }
}
```

Правим значения, коммитим — все 6 языковых версий подхватят их при загрузке страницы.
`rating` пишем через **точку** (это JSON), на странице разделитель подставится по локали:
`5,0` для sk/cs/de/ru/uk и `5.0` для en. `count` — целое число, «+» уже есть в вёрстке.

Как это работает: `app.js` читает `reviews.json` (путь резолвится относительно самого скрипта,
поэтому работает и в корне, и в `/ru/`, `/de/`…) и заполняет все элементы с атрибутом `data-rev`.
Значения, вписанные в HTML, — это фолбэк: если файл не загрузится, страница покажет их
и ничего не сломается. Поэтому в HTML стоит держать примерно актуальные числа.

### Что придётся править руками отдельно

`★ 5,0` в `<meta name="description">`, `og:description` и `twitter:description` (строки 7, 22, 27
в каждом из 6 файлов). Их **нельзя** обновить через JS: Google читает сырой HTML `<head>`,
а не отрендеренный DOM. Если рейтинг Google изменится — пройтись по ним поиском и заменить.

### Про автоматизацию

Полный автомат из Google возможен через Places API (`rating` + `userRatingCount`), но требует
ключа Google Cloud с биллингом. Разумный вариант — GitHub Actions по расписанию: ключ лежит
в Secrets, workflow переписывает `reviews.json` и цифры в meta, коммитит. Вёрстка к этому
уже готова — менять пришлось бы только источник данных.

У **Notino публичного API нет**, его цифры автоматизировать нечем — только вручную.
