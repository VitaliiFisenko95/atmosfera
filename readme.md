## 1. Хостинг (бесплатно)

### Вариант A — Cloudflare Pages (рекомендую)
Быстрый CDN, бесплатный SSL, нормальные хедеры, нет лимитов как у GH Pages.

1. dash.cloudflare.com → **Workers & Pages → Create → Pages → Upload assets**.
2. Перетащи 4 файла → Deploy. Получишь `https://<имя>.pages.dev`.
3. Когда будет домен: **Custom domains → добавить** (если домен на Cloudflare DNS — всё автоматом).

### Вариант B — GitHub Pages
1. Репо → закинуть файлы в корень → Settings → Pages → Deploy from branch `main` / root.
2. Кастомный домен: файл `CNAME` с доменом + A-записи GitHub (185.199.108–111.153) или CNAME на `<user>.github.io`.

---

## 2. Домен — единственная платная вещь, и она обязательна

Поддомены `*.pages.dev` / `*.github.io` в локальной выдаче Словакии не ранжируются нормально: нет сигнала локальности, нет траста, нельзя нормально привязать к Google Business Profile.

- `.sk` — websupport.sk или wedos.com, ~12–15 €/год. Для локального SEO в Словакии `.sk` ощутимо лучше `.com`.
- Идеи: `atmosferanails.sk`, `atmosfera-nails.sk`, `atmosferastudio.sk` (проверь свободность).
- Регистрировать лучше на владельца салона (или сразу оформить трансфер-доступ), чтобы бизнес не зависел от твоего аккаунта.

---

## 3. Google Search Console — сразу после деплоя

1. search.google.com/search-console → **Add property → Domain** → подтверждение через TXT-запись в DNS.
2. **Sitemaps** → отправить `https://домен/sitemap.xml`.
3. **URL Inspection** → главная → **Request indexing**.

Bing Webmaster Tools (bing.com/webmasters) — импортирует всё из GSC за минуту, лишним не будет.

---

## 4. Главный рычаг локального SEO — Google Business Profile

У салона уже есть карточка с **5,0★ и 106+ отзывами** — это их главный SEO-актив, сайт лишь усиливает его. Что должен сделать **владелец** (доступ к карточке только у него):

1. В карточке GBP → **Website** → вписать новый домен. Это даёт сайту главный сигнал локальности.
2. Добавить ссылку на сайт в bio Instagram/TikTok.
3. Продолжать собирать отзывы (можно через QR на стойке → прямая ссылка на отзыв в Google).
4. NAP-консистентность: название/адрес/телефон на сайте, в GBP и на Notino должны совпадать символ в символ (на сайте уже как в GBP).

Бесплатные словацкие каталоги для citations: **Azet.sk, Zoznam.sk, Firmy.sk** — завести карточки с тем же NAP + ссылкой.

## 5. Реалистичные ожидания (честно)

«Топ по всей Словакии по любому запросу про маникюр» — так локальный поиск не работает:

- По широким запросам («manikúra», «gélové nechty») Google показывает **локальный пак (карты)** + агрегаторы (Notino, Reservio, Fresha, Glamio). Одиночный лендинг их не перебьёт — и не должен.
- Google ранжирует локально: жительница Кошиц увидит салоны Кошиц, а не Братиславы.

**Что реально достижимо и что даёт клиентов:**

| Цель | Срок | За счёт чего |
|---|---|---|
| Топ-1 по бренду («atmosfera nails», «atmosféra bratislava») | 1–2 недели после индексации | сайт + GBP |
| Топ-3 в локальном паке «manikúra Ružinov», «pedikúra Ružinov» | уже почти есть | GBP 5,0★ + ссылка на сайт |
| Топ-10 органики «manikúra Bratislava», «podologická pedikúra Bratislava», «gélové nechty Ružinov» | 2–4 месяца | контент сайта + citations + отзывы |
| Топ по «манікюр братислава», «маникюр братислава» (укр/рус) | 1–2 месяца, конкуренция низкая | блок на сайте уже есть; можно добавить полные страницы `/ua/`, `/ru/` |

Подология — отдельная золотая ниша: «zarastený necht Bratislava», «podologická pedikúra» — конкуренция низкая, секция на сайте под это уже заточена.

**Следующий уровень (когда захочется):** отдельные страницы под услуги (`/gelove-nechty/`, `/pedikura/`, `/podologia/`) + 3–4 статьи из их же IG-контента («Ako dlho vydrží gel lak?» у них уже есть готовый пост — это идеальная статья). Скажи — сгенерим.
